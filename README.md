# 🎓 College Application Form

A simple and user-friendly **College Application Form** developed using HTML, CSS, and JavaScript. The project demonstrates client-side form validation and provides instant error messages for invalid or missing information.

## 📌 Project Overview

The College Application Form is designed to collect basic student information required during the admission process. JavaScript is used to validate the entered data before the application is submitted.

The form provides clear validation messages below the respective fields, making it easy for students to identify and correct errors.

## ✨ Features

- Student information collection
- Email validation
- Mobile number validation
- Register number validation
- Date of birth selection
- Department selection
- Percentage validation
- Gender selection
- Address input
- Declaration checkbox
- Real-time error messages
- Application success message
- Reset option

## 🛠️ Technologies Used

- HTML5 – Form structure
- CSS3 – Basic styling and layout
- JavaScript – Form validation
- Selenium IDE – Functional testing
